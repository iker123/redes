PRÁCTICA GUIADA · CÓMALO TÚ MISMO EN TU KALI

🖥️ Comandos que vas a ejecutar

Antes de jugar, prueba esto en tu propia máquina virtual (siempre contra localhost / 127.0.0.1, nunca contra la red de la universidad). Así entiendes de dónde sale cada evidencia que vas a leer en la misión.

1. Instalar el agente SNMP

sudo apt update sudo apt install snmpd snmp -y

2. Iniciar y verificar el servicio

sudo systemctl start snmpd sudo systemctl status snmpd

3. Consultar tu propio agente (snmpwalk)

snmpwalk -v2c -c public localhost

4. Ver dónde vive la "contraseña" (community string)

sudo cat /etc/snmp/snmpd.conf | grep -i community

5. Confirmar el puerto abierto con nmap

nmap -sU -p161 --script snmp-info localhost

6. Leer solo el nombre del sistema (un OID específico)

snmpget -v2c -c public localhost sysName.0
⚠️ Todos estos comandos se ejecutan contra tu propia máquina (localhost). Nunca los uses contra la red de la UDABOL ni contra ningún equipo que no sea tuyo o de tu laboratorio.
